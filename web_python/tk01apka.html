Výzvy

1. První okno (10 minut)

Vytvoření aplikace

import tkinter as tk

okno = tk.Tk()

okno.title("Moje první aplikace")
okno.geometry("400x300")

okno.mainloop()

Vysvětlení

tk.Tk()

vytvoří okno.

title()

nastaví název.

geometry()

nastaví velikost.

mainloop()

spustí aplikaci.

Úkol

Změňte:

  • název okna
  • velikost okna

2. Přidání textu (10 minut)

Widget Label

import tkinter as tk

okno = tk.Tk()

nadpis = tk.Label(
    okno,
    text="Vítej v aplikaci!",
    font=("Arial", 20)
)

nadpis.pack()

okno.mainloop()

Co dělá pack()?

Umístí prvek do okna.

nadpis.pack()

bez něj nebude widget vidět.

Úkol

Změňte text na vlastní uvítání.

3. Přidání tlačítka (15 minut)

První tlačítko

import tkinter as tk

okno = tk.Tk()

def pozdrav():
    print("Ahoj!")

tlacitko = tk.Button(
    okno,
    text="Klikni"
)

tlacitko.pack()

okno.mainloop()

Tlačítko zatím nic nedělá.

Přidání funkce

tlacitko = tk.Button(
    okno,
    text="Klikni",
    command=pozdrav
)

Úkol

Po kliknutí vypište:

print("Funguje to!")

4. Zobrazování textu v okně (10 minut)

Místo výpisu do konzole budeme měnit text v aplikaci.

Kód

import tkinter as tk

okno = tk.Tk()

text = tk.Label(
    okno,
    text="Stiskni tlačítko"
)

text.pack()

def zmena():
    text.config(text="Ahoj světe!")

tlacitko = tk.Button(
    okno,
    text="Klikni",
    command=zmena
)

tlacitko.pack()

okno.mainloop()

Novinka

config()

umožňuje měnit vlastnosti widgetu.

5. Hlavní projekt – Generátor výzev (25 minut)

Zadání

Vytvoříme aplikaci, která po kliknutí zobrazí náhodný úkol.

Například:

  • Udělej 5 dřepů
  • Usměj se
  • Řekni vtip
  • Napij se vody
  • Pozdrav spolužáka

Krok 1 – import random

import random

Krok 2 – seznam výzev

vyzvy = [
    "Udělej 5 dřepů",
    "Usměj se",
    "Řekni vtip",
    "Napij se vody",
    "Pozdrav spolužáka",
    "Protáhni se",
    "Zatleskej"
]

Krok 3 – vytvoření popisku

vysledek = tk.Label(
    okno,
    text="Klikni na tlačítko",
    font=("Arial", 16)
)

vysledek.pack(pady=20)

Krok 4 – funkce pro výběr

def nova_vyzva():
    vyzva = random.choice(vyzvy)
    vysledek.config(text=vyzva)

Krok 5 – tlačítko

tlacitko = tk.Button(
    okno,
    text="Losuj výzvu",
    command=nova_vyzva
)

tlacitko.pack()

Kompletní řešení

import tkinter as tk
import random

okno = tk.Tk()

okno.title("Generátor výzev")
okno.geometry("500x300")

vyzvy = [
    "Udělej 5 dřepů",
    "Usměj se",
    "Řekni vtip",
    "Napij se vody",
    "Pozdrav spolužáka",
    "Protáhni se",
    "Zatleskej"
]

vysledek = tk.Label(
    okno,
    text="Klikni na tlačítko",
    font=("Arial", 16)
)

vysledek.pack(pady=20)

def nova_vyzva():
    vyzva = random.choice(vyzvy)
    vysledek.config(text=vyzva)

tlacitko = tk.Button(
    okno,
    text="Losuj výzvu",
    command=nova_vyzva
)

tlacitko.pack()

okno.mainloop()
