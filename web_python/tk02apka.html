Kámen, nůžky, papír

Cíle hodiny

Student:

  • vytvoří grafickou aplikaci pomocí Tkinteru
  • naučí se reagovat na kliknutí tlačítek
  • využije podmínky if
  • použije knihovnu random
  • vytvoří jednoduchou hru proti počítači

Výstup

Na konci hodiny bude mít každý student funkční hru Kámen, nůžky, papír.

1. Úvod (10 minut)

Co budeme vytvářet?

Hru proti počítači.

Pravidla:

  • Kámen porazí nůžky
  • Nůžky porazí papír
  • Papír porazí kámen

Počítač bude losovat svůj tah náhodně.

Ukázka aplikace

KÁMEN NŮŽKY PAPÍR

Počítač zvolil: kámen

[Vyber kámen]
[Vyber nůžky]
[Vyber papír]

Výsledek: Vyhrál jsi!

2. Vytvoření okna (10 minut)

Základ aplikace

import tkinter as tk

okno = tk.Tk()

okno.title("Kámen, nůžky, papír")
okno.geometry("500x400")

okno.mainloop()

Úkol

Změň:

  • velikost okna
  • název aplikace

3. Přidání nadpisu (5 minut)

nadpis = tk.Label(
    okno,
    text="KÁMEN, NŮŽKY, PAPÍR",
    font=("Arial", 20)
)

nadpis.pack(pady=20)

Vysvětlení

font=("Arial", 20)

nastavuje velikost písma.

pady=20

přidá mezeru kolem widgetu.

4. Zobrazení výsledků (10 minut)

Připravíme místo pro zobrazení tahu počítače.

tah_pc = tk.Label(
    okno,
    text="Počítač ještě nehrál",
    font=("Arial", 14)
)

tah_pc.pack()

A také výsledek hry.

vysledek = tk.Label(
    okno,
    text="Vyber svůj tah",
    font=("Arial", 16)
)

vysledek.pack(pady=20)

5. Náhodný tah počítače (10 minut)

Import knihovny

import random

Možné tahy

moznosti = [
    "kámen",
    "nůžky",
    "papír"
]

Test

print(random.choice(moznosti))

Po každém spuštění dostaneme náhodný výsledek.

6. Funkce pro hru (20 minut)

První verze

def hraj(tah_hrace):

    tah_pocitace = random.choice(moznosti)

    tah_pc.config(
        text=f"Počítač zvolil: {tah_pocitace}"

Kompletní funkce

def hraj(tah_hrace):

    tah_pocitace = random.choice(moznosti)

    tah_pc.config(
        text=f"Počítač zvolil: {tah_pocitace}"
    )

    if tah_hrace == tah_pocitace:
        vysledek.config(text="Remíza")

    elif (
        (tah_hrace == "kámen" and tah_pocitace == "nůžky")
        or
        (tah_hrace == "nůžky" and tah_pocitace == "papír")
        or
        (tah_hrace == "papír" and tah_pocitace == "kámen")
    ):
        vysledek.config(text="Vyhrál jsi!")

    else:
        vysledek.config(text="Vyhrál počítač!")

7. Tlačítka hráče (10 minut)

Kámen

btn_kamen = tk.Button(

    text="Kámen",

)

btn_kamen.pack()

Nůžky

btn_nuzky = tk.Button(
    okno,
    text="Nůžky",
    command=lambda: hraj("nůžky")
)

btn_nuzky.pack()

Papír

    okno,
    text="Papír",
    command=lambda: hraj("papír")
)

btn_papir.pack()

Novinka – lambda

Potřebujeme předat funkci parametr.

command=lambda: hraj("kámen")

znamená:

Po kliknutí zavolej funkci hraj() a pošli jí hodnotu "kámen".

8. Kompletní řešení

import tkinter as tk
import random

okno = tk.Tk()

okno.title("Kámen, nůžky, papír")
okno.geometry("500x400")

moznosti = [
    "kámen",
    "nůžky",
    "papír"
]

nadpis = tk.Label(
    okno,
    text="KÁMEN, NŮŽKY, PAPÍR",
    font=("Arial", 20)
)

nadpis.pack(pady=20)

tah_pc = tk.Label(
    okno,
    text="Počítač ještě nehrál",
    font=("Arial", 14)
)

tah_pc.pack()

vysledek = tk.Label(
    okno,
    text="Vyber svůj tah",
    font=("Arial", 16)
)

vysledek.pack(pady=20)

def hraj(tah_hrace):

    tah_pocitace = random.choice(moznosti)

    tah_pc.config(
        text=f"Počítač zvolil: {tah_pocitace}"
    )

    if tah_hrace == tah_pocitace:
        vysledek.config(text="Remíza")

    elif (
        (tah_hrace == "kámen" and tah_pocitace == "nůžky")
        or
        (tah_hrace == "nůžky" and tah_pocitace == "papír")
        or
        (tah_hrace == "papír" and tah_pocitace == "kámen")
    ):
        vysledek.config(text="Vyhrál jsi!")

    else:
        vysledek.config(text="Vyhrál počítač!")

btn_kamen = tk.Button(
    okno,
    text="Kámen",
    command=lambda: hraj("kámen")
)

btn_kamen.pack()

btn_nuzky = tk.Button(
    okno,
    text="Nůžky",
    command=lambda: hraj("nůžky")
)

btn_nuzky.pack()

btn_papir = tk.Button(
    okno,
    text="Papír",
    command=lambda: hraj("papír")
)

btn_papir.pack()

okno.mainloop()
